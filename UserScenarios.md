## User Scenarios

# Scenario: User specific teaching and feedback

--> User uploads a small set of GRE questions they found challenging
--> Tutor demonstrates multi-approach explanations for each question (visual, step-by-step, conceptual)
--> Tutor identifies patterns in user's misconceptions across the sample questions
--> Tutor gauges user's understanding and recetiveness to the explanations, cand can adjust explanation complexity based on user preference
--> User prompts "ask for clarification" on explanations they still find confusing

# Scenario: First-Time User: Verbal-Strong/Quant-Weak Profile

--> Tutor asks for practice test results or self-assessment of abilities
--> Tutor analyzes results and identifies specific quantitative weaknesses (e.g., geometry, data interpretation)
--> Tutor validates verbal strengths while suggesting targeted maintenance practice
--> Tutor provides an accessible explanation of a previously missed quantitative problem, using verbal/visual aids
--> Tutor suggests a balanced study plan with x% focus on quantitative remediation, starting with foundational concepts
--> Tutor shares specific strategies for translating word problems into mathematical expressions
--> Tutor ends with confidence-building exercise focused on quantitative content

# Scenario: First-Time User: Quant-Strong/Verbal-Weak Profile

--> Tutor asks for practice test results or self-assessment of abilities
--> User uploads results 
--> Tutor analyzes results to identify specific verbal challenges (e.g., reading comprehension, text completion)
--> Tutor validates quantitative strengths while suggesting targeted maintenance practice
--> Tutor walks through a previously missed verbal question, demonstrating effective elimination strategies
--> Tutor introduces vocabulary-building system tailored to GRE frequency lists
--> Tutor creates study plan with x% focus on verbal section improvement (as needed based on score)
--> Tutor demonstrates reading comprehension strategies that leverage analytical thinking skills
--> Tutor concludes with suggested reading materials at appropriate difficulty levels

# Scenario: First-Time User: Balanced Profile with Test Anxiety

--> User uploads results showing balanced scores (rouhgly 65th percentile Verbal, 68th percentile Quantitative)
--> User reports experiencing time management issues and "mental blanks" during practice tests
--> Tutor acknowledges anxiety concerns and introduces integrated stress management techniques
--> Tutor analyzes performance patterns related to anxiety (e.g., declining accuracy in final third of sections)
--> Tutor demonstrates strategic guessing approaches when facing time pressure
--> Tutor introduces structured approach to pacing with specific time benchmarks
--> Tutor creates study plan integrating deliberate stress exposure with relaxation techniques
--> Session includes practice with a small set of questions under timed conditions with anxiety-reduction strategies
--> Tutor assigns pre-test routines to establish before next practice exam
